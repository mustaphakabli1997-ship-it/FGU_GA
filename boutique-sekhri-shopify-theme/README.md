# Boutique Sekhri — ثيم Shopify

ثيم Shopify (Online Store 2.0) بالهوية البصرية تاع Boutique Sekhri: أسود مات، فضي معدني، برتقالي نيون، شعار BS.
نفس تصميم الموقع الأول لكن يخدم داخل Shopify: المنتجات والسلة والدفع والطلبات والإيميلات كلها تسيّرها Shopify.

> هذا المجلد هو **مصدر** الثيم. الملف اللي ترفعه لـShopify هو `boutique-sekhri-shopify-theme.zip`
> (ملفات الثيم لازم تكون في **جذر** الـzip: `layout/`, `sections/`, `templates/`… مباشرة، وليس داخل مجلد).

## 1) رفع الثيم

Shopify ← **Boutique en ligne** ← **Thèmes** ← **Importer** ← **Charger un fichier zip** ← اختر الملف ← بعد الرفع: **… ← Publier**
(أو **Modifier le thème** لتجربته قبل النشر).

## 2) إعداد المتجر (في لوحة Shopify)

| الخطوة | وين |
|---|---|
| **المنتجات**: أضفها بصور، وخيارات `Taille` (S…3XL) و`Couleur` | Produits |
| **الألوان بدوائر ملونة**: في خيار `Couleur` اربط كل لون بـ«swatch» (لون أو صورة) | Produits ← خيارات ← تعديل |
| **الأقسام**: أنشئ collections (Ensembles, Tricots, Pantalons…) وضع لكل واحدة صورة | Produits ← Collections |
| **القائمة العلوية**: القائمة `main-menu` تظهر في الهيدر (روابط الأقسام) | Contenu ← Menus |
| **الدفع عند الاستلام**: فعّل «Paiement à la livraison (COD)» | Paramètres ← Paiements ← Modes de paiement manuels |
| **التوصيل**: أنشئ أسعار الشحن للجزائر (الولايات تظهر تلقائياً في العنوان) | Paramètres ← Expédition et livraison |
| **العربية**: أضف اللغة العربية فيظهر زر اللغة في الهيدر | Paramètres ← Langues |
| **الشعار / الألوان / واتساب / السوشيال**: في إعدادات الثيم | Thèmes ← Modifier le thème ← Paramètres du thème |
| **كلمة سر المتجر** (متاجر التجربة مقفولة افتراضياً) | Boutique en ligne ← Préférences |

نصوص الأقسام (الهيرو، الشريط البرتقالي…) تتبدل من **Modifier le thème** بدون كود. ولترجمتها للعربية استعمل تطبيق
**Translate & Adapt** (ترجمات الواجهة الثابتة: السلة، المنتج، البحث… موجودة جاهزة بالفرنسية والعربية).

## 3) الإيميل عند كل منتج جديد

الثيم ما يقدرش يبعت إيميلات (هذا شغل Shopify)، لكن:

- خانة **اشتراك اختيارية** في الصفحة الرئيسية، أسفل كل صفحة، وزر الجرس 🔔. اللي يشترك يتسجل في **Clients** كزبون
  بموافقة تسويق بريدي ووسم `newsletter`. ما كاين أي نافذة تظهر مجبرة عند الدخول.
- لإرسال إيميل بالشعار عن منتج جديد: **Marketing ← Shopify Email** ← أنشئ حملة، أضف المنتج وأرسلها للمشتركين.
  هذا **يدوي لكل حملة** (ماشي أوتوماتيكي مثل الموقع الأول). وجود أتمتة رسمية «منتج جديد ← إيميل» في Shopify (Flow أو تطبيق آخر)
  ما تحققتش منه، فراجعه قبل الاعتماد عليه.

## ما يحتويه

- **الصفحة الرئيسية** (كلها قابلة للتعديل وإعادة الترتيب): شريط إعلانات متحرك، هيرو بالشعار، شريط الكلمات، الأقسام، المنتجات الجديدة،
  القطعة المميزة، المزايا، الشعار الكبير، النشرة.
- **المنتج**: معرض صور، دوائر ألوان، مقاسات، سعر وتخفيض، «أضف للسلة» (AJAX) و«اطلب الآن»، شريط شراء ثابت على الموبايل، منتجات مشابهة.
- **القسم**: ترتيب وفلترة (عبر Search & Discovery)، ترقيم صفحات. **السلة**: سلة جانبية أو صفحة، شريط التوصيل المجاني.
- بحث، مدونة، صفحات، 404، صفحة كلمة السر، عربي RTL كامل، بدون أي مكتبة JavaScript خارجية، والخطوط داخل الثيم.

## ملاحظات صريحة

- جرّبته محلياً بمحاكاة Liquid ببيانات وهمية (المظهر، اختيار اللون والمقاس، السلة الجانبية، العربية، الموبايل)، وفحصته بأداة
  Shopify الرسمية **Theme Check: 0 أخطاء، 0 تحذيرات**. لكن ما رفعتهوش على متجر Shopify حقيقي، فراجع كل صفحة بعد الرفع.
- صفحات حسابات الزبائن (login/register) غير مضمّنة لأن الحسابات الجديدة تستضيفها Shopify نفسها. إذا فعّلت «الحسابات الكلاسيكية» نحتاج نضيفها.
- المنتجات والصور لازم تضيفها أنت: الثيم ما فيهش رسومات الملابس تاع الموقع الأول، يعرض صور منتجاتك الحقيقية.
- نص «توصيل إلى 58 ولاية» و«الدفع عند الاستلام» في الثيم نصوص افتراضية؛ عدّلها حسب سياستك.

## التطوير

```bash
npx @shopify/cli theme dev --store <متجرك>.myshopify.com    # معاينة مباشرة
npx @shopify/cli theme check                                # فحص الثيم
```
