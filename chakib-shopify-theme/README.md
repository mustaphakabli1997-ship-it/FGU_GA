# Chakib — ثيم Shopify فخم لمتجر الماركات

ثيم Shopify (Online Store 2.0) بهوية **Chakib**: أسود فحمي، ذهبي ملكي، عاجي، وخط Serif راقٍ، والشعار الذهبي بالتاج.
مصمم لمتجر أزياء رجالية **متعدد الماركات** (Prada، Moncler، Lacoste، Balmain…).

> هذا المجلد هو **مصدر** الثيم. الملف اللي ترفعه لـShopify هو `chakib-shopify-theme.zip`
> (ملفات الثيم في **جذر** الـzip: `layout/`, `sections/`, `templates/`… مباشرة).

## 1) رفع الثيم
**Boutique en ligne ← Thèmes ← Importer ← Charger un fichier zip** ← اختر الملف ← **… ← Publier** (أو **Modifier le thème** للتجربة أولاً).

## 2) الماركات (الأهم لمتجرك)
- في كل منتج، حقل **Fournisseur (Vendor)** = اسم الماركة: `Prada` أو `Moncler` أو `Lacoste` أو `Balmain`.
  يظهر الاسم بالذهبي فوق اسم المنتج في البطاقة وصفحة المنتج، ويصير رابطاً لصفحة الماركة تلقائياً.
- قسم **Nos maisons** في الصفحة الرئيسية: بلاطة لكل ماركة. ضع لها صورة خلفية (Modifier le thème ← Nos maisons ← Marque)،
  وبدون صورة تظهر بإطار ذهبي وحرفها الأول. رابطها يعرض كل المنتجات اللي **Fournisseur** تاعها هو نفس الاسم، أو اختر Collection.
- **الشريط المتحرك** (Prada ✦ Moncler ✦ …) والقائمة العلوية تتعدلان بدون كود. أضف الماركات الجديدة بنفس الطريقة.
- **تنبيه:** أسماء الماركات علامات تجارية لأصحابها. الثيم يعرضها **كنص فقط** بدون أي شعار لهم. بع منتجات أصلية من مصادر
  معتمدة، ولا تستعمل صور حملاتهم الرسمية أو شعاراتهم بدون ترخيص.

## 3) إعداد المتجر
| الخطوة | وين |
|---|---|
| المنتجات بصور (3:4 عمودية أحسن)، وخيارات `Taille` و`Couleur` | Produits |
| دوائر الألوان: اربط كل لون بـ«swatch» في خيار `Couleur` | Produits ← خيارات |
| الأقسام: collections بصور (الموزاييك يأخذ صورة الـcollection) | Produits ← Collections |
| القائمة العلوية (`main-menu`) وقائمة الفوتر (`footer`) | Contenu ← Menus |
| الدفع عند الاستلام: فعّل COD | Paramètres ← Paiements ← Modes de paiement manuels |
| أسعار الشحن للجزائر | Paramètres ← Expédition et livraison |
| اللغة العربية (يظهر زر اللغة في الهيدر) | Paramètres ← Langues |
| الشعار، الألوان، واتساب، السوشيال | Thèmes ← Modifier le thème ← Paramètres du thème |
| كلمة سر المتجر (متاجر التجربة مقفولة افتراضياً) | Boutique en ligne ← Préférences |

نصوص الأقسام تتبدل من **Modifier le thème**، وللترجمة العربية استعمل **Translate & Adapt** (نصوص الواجهة الثابتة جاهزة بالفرنسية والعربية).

## 4) الإيميل
- خانة اشتراك **اختيارية** (قسم «Rejoins le Cercle» وأسفل الصفحات، وجرس في الهيدر)، بلا نافذة مجبرة.
  المشترك يتسجل في **Clients** بموافقة تسويق بريدي ووسم `newsletter`.
- لإرسال إيميل عن قطعة جديدة: **Marketing ← Shopify Email** (حملة يدوية). أتمتة «منتج جديد ← إيميل» ما تحققتش منها.

## 5) تخصيص تطبيق نموذج الطلب (COD / WEBI LeadForm)
الإصدار 1.0.1 فيه خانة **CSS personnalisé** (Thèmes ← Modifier le thème ← Paramètres du thème) تقدر تلصق فيها CSS لتنسيق أي تطبيق بهوية Chakib.
القيم الجاهزة (ألوان، نصوص، CSS) في صفحة «Fiche COD Chakib». أسماء عناصر التطبيق في ذلك الـCSS عامة وغير مؤكدة، فإذا ما تغيّر شيء أرسل صورة النموذج.

## ما يحتويه
هيرو تحريري بإطار ذهبي، شريط الماركات المتحرك، «Nos maisons»، موزاييك الأقسام، شبكة منتجات، القطعة المميزة (Editorial)،
بانر صورة، المزايا، اقتباس كبير، النشرة. صفحة المنتج (صور، ألوان، مقاسات، «أضف للسلة» AJAX، شريط شراء للموبايل)،
القسم (ترتيب وفلاتر)، السلة الجانبية، البحث، المدونة، 404، صفحة كلمة السر، عربي RTL كامل، بلا مكتبات JavaScript خارجية والخطوط داخل الثيم.

## ملاحظات صريحة
- **الألوان** أخذتها من الشعار نفسه (ذهبي `#fee490 → #e0bd69 → #af8a46` على `#0f1014`) لأن الأكواد المكتوبة في لوحة الهوية غير واضحة.
- الشعار مُحوَّل إلى SVG من صورتك (ذهبي بتدرج) داخل الثيم؛ ارفع شعارك الأصلي من إعدادات الثيم إن أردت دقة أعلى.
- فحصته بأداة Shopify الرسمية **Theme Check: 0 أخطاء، 0 تحذيرات**، وجرّبته محلياً بمحاكاة Liquid ببيانات وهمية (الصفحة الرئيسية، المنتج، القسم، السلة، العربية، الموبايل).
  **ما رفعتهوش على متجر Shopify حقيقي**، فراجع كل صفحة بعد الرفع.
- صور الثيم تعتمد على صورك: بدونها تظهر إطارات ذهبية بالتاج. لا توجد صور ملابس مضمّنة.
- صفحات حسابات الزبائن (login/register) غير مضمّنة لأن الحسابات الجديدة تستضيفها Shopify نفسها.
- النصوص الافتراضية («توصيل 58 ولاية»، «الدفع عند الاستلام») عدّلها حسب سياستك.
