# قالب متجر ملابس نسائية

صفحة واحدة جاهزة: واجهة، مجموعات، منتجات مع مقاسات وألوان، سلة، وإرسال الطلب عبر واتساب. عربي (RTL) + إنجليزي.

## الاستعمال
1. افتح `config.js` وعدّل: اسم المتجر، الألوان، **رقم واتساب** (`whatsapp`)، المنتجات.
2. للصور: ضع الصور في مجلد `images/` واكتب مسارها في `image` لكل منتج (مثال `"images/p1.jpg"`).
3. افتح `index.html` في المتصفح، أو انشره على GitHub Pages / Netlify.

## ما يحتاج ضبطك
- نصوص الميزات (التوصيل، الدفع، الاستبدال) أمثلة فقط، عدّلها لتطابق سياسة المتجر.
- لتفعيل GA4 ضع معرّفك في `ga4`.
- الطلب يصل كرسالة واتساب جاهزة، وليس هناك دفع إلكتروني ولا قاعدة بيانات.
