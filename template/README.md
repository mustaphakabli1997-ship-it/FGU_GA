# قالب متجر ملابس نسائية (طلب بسيط، الدفع عند الاستلام)

1. الزبون يتصفح الموديلات.
2. يضغط على الموديل فتفتح نافذة فيها اللون والسعر والمقاس والكمية.
3. يكتب: الاسم، الولاية (58 ولاية)، البلدية، رقم الهاتف.
4. يضغط "تأكيد الطلب" فتصلك رسالة واتساب جاهزة فيها كل التفاصيل. الدفع عند الاستلام، والتوصيل لباب المنزل 600 دج.

## التعديل (كله في `config.js`)
- `whatsapp`: رقم واتساب الذي تصله الطلبات (دولي بدون +) — **غيّريه**.
- `order.deliveryFee`: سعر التوصيل (600).
- `products`: الموديلات (الاسم، السعر، المقاسات، الألوان، `image`).
- `colorNames`: اسم كل لون كما يظهر في رسالة الطلب.
- `t`: كل النصوص. `colors`: ألوان المتجر. `ga4`: معرّف GA4 اختياري.

## ملاحظة
الطلب يصل كرسالة واتساب فقط (لا قاعدة بيانات ولا لوحة إدارة).
