# YOUZ Streetwear — متجر الأحذية (بالفرنسية) مع فورم COD

موقع ثابت (HTML / CSS / JS) بدون أي أدوات بناء: يشتغل على أي استضافة، ويمكن فتحه مباشرة بالضغط مرتين على `index.html`.
التصميم مأخوذ من اللوقو والهوية البصرية: أسود · رمادي فحمي · فضي كروم · أبيض، أزرار pill، نجوم، grain و spray.

## الصفحات
| الملف | الدور |
|---|---|
| `index.html` | الرئيسية: Hero، شبكة المنتجات (Nouveautés + فلاتر)، Drop، طريقة الطلب، أسعار التوصيل، FAQ |
| `produit.html?id=…` | صفحة المنتج + **فورم الطلب COD** (هذا الرابط هو الذي تضعه في إعلانات فيسبوك/تيك توك) |

## الفورم (Paiement à la livraison)
الحقول: الاسم · الهاتف (05/06/07 مع تنظيف +213 والأرقام العربية) · الولاية (58) · البلدية · نوع التوصيل
(À domicile / Stop Desk) · العنوان · المقاس · اللون · الكمية.
ملخص مباشر: ثمن المنتج + سعر التوصيل حسب الولاية = المجموع. يوجد honeypot ضد البوتات، وتحقق كامل برسائل بالفرنسية،
ونافذة تأكيد برقم الطلب `YZ-XXXXXXXX`.

## 1) الإعدادات — ملف `js/config.js` فقط
- `whatsapp`: رقمك بالصيغة الدولية بدون + (مثال `"213550123456"`). إذا تركته فارغًا تختفي أزرار واتساب.
- `phone`, `social.instagram / tiktok / facebook`: تظهر فقط إذا وضعت قيمة.
- `delivery`: أسعار التوصيل لكل منطقة (A/B/C/D) — **أرقام تقريبية، عدّلها حسب شركة التوصيل** (Yalidine, ZR Express, Ecotrack…).
  منطقة كل ولاية في `js/wilayas.js`.
- `freeDeliveryOver`: توصيل مجاني ابتداءً من مبلغ معيّن (`0` = معطّل).

## 2) المنتجات — ملف `js/products.js`
انسخ أي كتلة منتج وغيّر: `id` (فريد وبدون فراغات) · `name` · `price` · `oldPrice` · `images` · `sizes` · `soldOutSizes`.
ضع الصور في `assets/products/`. رابط المنتج: `produit.html?id=<id>`.

> ⚠ الصور والأسعار الحالية **أمثلة** (مقتطعة من التصميم المعروض). استبدلها بصور منتجاتك الحقيقية (مقترح 1000×1150 px، JPG).
> نصوص FAQ وسياسة الاستبدال (7 أيام) ومدة التوصيل في `index.html` أيضًا أمثلة — عدّلها حسب سياستك.

## 3) استقبال الطلبات في Google Sheets
1. أنشئ Google Sheet فارغ ← Extensions ← Apps Script.
2. الصق محتوى `google-apps-script/Code.gs` (واختياريًا ضع بريدك في `NOTIFY_EMAIL`).
3. Deploy ← New deployment ← Web app ← *Execute as: Me* · *Who has access: Anyone*.
4. انسخ الرابط الذي ينتهي بـ `/exec` وضعه في `js/config.js` ← `orderEndpoint`.

⚠ **إلى أن تفعل هذه الخطوة الموقع في «Mode démo»**: الفورم يعمل لكن الطلب لا يُرسَل لأي مكان (وتظهر رسالة تنبيه في نافذة التأكيد).

## 4) النشر
- **Netlify / Vercel / Cloudflare Pages**: Publish directory = `youz-store`.
- **GitHub Pages**: انقل محتوى هذا المجلد إلى جذر المستودع (أو إلى `/docs`). ملاحظة: `index.html` الموجود حاليًا في جذر المستودع هو موقع GA4 التجريبي ولم أمسّه.
- بعد النشر: ضع رابط الموقع الكامل في وسوم `og:image` (لمعاينة المشاركة على فيسبوك/واتساب) ورابط الدومين في `produit.html` و `index.html`.

## 5) البيكسل (اختياري)
الكود يرسل تلقائيًا الأحداث `ViewContent` و `InitiateCheckout` و `Purchase` (Meta) و `view_item` / `begin_checkout` / `purchase` (GA4)
إذا أضفت سنيبت Meta Pixel أو gtag داخل `<head>` في الصفحتين — لا حاجة لتعديل أي كود آخر.
